READ THE FIELD / 读现场

四个观察点，
决定泵站是否可信。

参考图里的设备关系不是装饰：吸入侧、驱动侧、出口侧、土建侧，每一处都对应真实的安装约束。

01INTAKE

吸入侧

圆筒滤网必须低于最低水位，吸入管不能形成气囊；滤网需要可提升、可清洗。

02DRIVE

驱动侧

132S 轴高 132 mm，泵轴与电机轴同轴；联轴器护罩包住旋转件，但不碰轴。

03DISCHARGE

出口侧

泵 → 止回阀 → 闸阀 → 压力表；出口管需要支架，阀门手轮要可操作。

04CIVIL

土建侧

湿混凝土泵台、地脚螺栓、排水坡和检修通道共同决定泵组能否长期稳定运行。

APPLICATION NOTES / 应用说明

不是把电机放进风景里，
而是把它放回驱动链中。

01

读安装关系

泵组底座、泵脚、电机脚、联轴器护罩和吸入/出口法兰，决定了电机的安装姿态与维护空间。

02

读负载特性

离心泵接近平方转矩；阀门开度、扬程和管路阻力改变实际流量与轴功率，启动方式影响冲击。

03

读环境边界

户外潮湿、晨露、泥水与连续灌溉季，对应 IP55、防腐、滤网清理和检修窗口。
