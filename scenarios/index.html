DRIVE / 传动直联 · 1440 r/min

START-UP / 启动顺序充水 → 启动 → 开阀

确认吸入阀开启并充水排气；启动电机；缓慢开启出口阀至工况点；检查压力、电流、振动与轴封。

ENVIRONMENT / 环境边界户外灌渠 + 田间管网

IP55 / IC411 / IM B3，S1 连续工作制；吸入侧设置滤网，出口侧设置止回阀与压力表。

APPLICATION NOTES / 应用说明

不是把电机放进风景里，
而是把它放回驱动链中。

01

读安装关系

泵组的联轴器护罩、输送机的减速驱动、风机的叶轮与搅拌器的侧入轴，决定了电机的安装姿态与维护空间。

02

读负载特性

泵与风机接近平方转矩，输送机与搅拌器接近恒转矩；启动方式、惯量和环境温度会改变实际负载率。

03

读环境边界

户外潮湿、屋顶风雪、室内班次与水处理湿气，分别对应不同的防护、防腐和维护要求。

页面展示安装关系、载荷路径与运行状态，用于解释性模拟；未进行结构强度、基础振动、热平衡或选型计算。
