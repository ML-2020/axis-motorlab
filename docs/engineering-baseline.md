## 2. 电气单线基线

```text
400 V / 50 Hz / 3P
        │
      MCCB / 熔断器组合（短路保护）
        │
      接触器 + 热过载/电机保护器
      或 软启动器
      或 变频器（VFD）
        │
      动力电缆（含 PE）
        │
      YE3-132S-4  5.5 kW
        │
      PE 排 / 等电位联结
```

### 启动方式

| 方式 | 典型启动电流 | 适用 | 注意 |
|---|---|---|---|
| DOL 直接启动 | 6–7 × FLC（约 67–78 A） | 小惯量、电网允许 | 电压跌落、机械冲击 |
| 星三角 | 约 1/3 启动转矩/电流 | 6 端子电机、轻载 | 不适合高惯量 |
| 软启动 | 约 2–3 × FLC | 泵、风机 | 旁路、散热 |
| VFD | 可限流/限转矩 | 变转矩泵/风机 | 谐波、dv/dt、屏蔽电缆 |

### 保护与监测

- 短路：MCCB 或熔断器，按 IEC 60947 / GB/T 14048；
- 过载：热继电器或电子电机保护器，按 FLC/服务系数整定；
- 缺相/相序/堵转：电机保护器；
- 接地故障：按系统接地型式（TN/TT）设计；
- 防雷/浪涌：配电柜侧 SPD；
- 电机热保护：PTC/PT100（按需要）；
- 急停/隔离：现场急停、可锁隔离开关；
- 控制电源：230 V AC 或 24 V DC，按柜体设计。

> 电流、电缆截面、保护整定、短路容量、电压降、谐波都必须按项目计算，本文不给“通用答案”。

## 3. 工艺与物化基线

| 场景 | 介质 | 主要材料 | 关键工艺风险 |
|---|---|---|---|
| 稻田灌溉 | 常温清水/泥水 | 铸铁、镀锌钢、青铜 | 滤网堵塞、吸入空气、水位过低 |
| 大棚滴灌 | 清水 + 肥料 | PP/PVC、不锈钢、铸铁 | 过滤器压差、肥液腐蚀、分区轮灌 |
| 鱼塘循环 | 养殖水 | 铸铁/不锈钢、防腐涂层 | 生物污损、含盐、连续运行 |
| 田间排涝 | 泥水、草屑 | 铸铁、抗堵叶轮 | 堵塞、干转、液位控制 |
| 冷冻水循环 | 闭式清水 + 药剂 | 铸铁、碳钢、青铜 | 压差、气蚀、旁通、保温 |
| 冷却塔风机 | 循环水/湿空气 | 镀锌钢、防腐涂层 | 漂水、结垢、皮带张紧 |
| 污水提升 | 污水、H₂S | 铸铁/不锈钢、防腐 | 堵塞、H₂S 腐蚀、密封泄漏 |
| 曝气风机 | 空气 | 铸铁、钢、橡胶 | 出口压力、超压、过滤器堵塞 |
| 皮带输送 | 散料/粉尘 | 碳钢、橡胶 | 带载启动、堵料、跑偏 |
| 搅拌机 | 水/污泥/药剂 | 不锈钢、碳钢、衬胶 | 启动惯量、沉渣、减速机过载 |

### 化学相容性

实际材料选择必须基于水质分析：

- pH；
- 氯离子；
- 硫酸盐；
- 悬浮物/磨蚀性；
- H₂S；
- 温度；
- 药剂种类和浓度。

不能仅凭“清水/污水”选材质。

## 4. 场景仪表与联锁基线

| 场景 | 主要仪表 | 主要联锁 |
|---|---|---|
| 稻田灌溉 | 出口压力、流量、液位 | 低液位停泵、过载、缺相 |
| 大棚滴灌 | 压力、过滤器压差、流量 | 超压、过滤器堵塞、分区阀 |
| 鱼塘循环 | 液位、流量、溶解氧（可选） | 低液位、过载、缺氧报警 |
| 田间排涝 | 液位、出口压力、流量 | 高液位启泵、低液位停泵、干转 |
| 冷冻水循环 | 压差、流量、供回水温度 | 压差过低、过载、连锁停机 |
| 冷却塔风机 | 振动、轴承温度、风机转速 | 超振、超温、皮带断裂 |
| 污水提升 | 液位、压力、密封泄漏 | 高液位报警、干转、过载 |
| 曝气风机 | 出口压力、温度、过滤器压差 | 超压泄放、超温、止回阀 |
| 皮带输送 | 速度、跑偏、拉绳、电流 | 跑偏、堵料、拉绳、过载 |
| 搅拌机 | 电流/转矩、液位、减速机温度 | 过载、低液位、减速机超温 |
