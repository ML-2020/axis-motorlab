## 4. 图里需要修正的工程问题

这是一张生成图，不是施工图。建模时不能照抄以下地方：

1. **泵和电机的相对高度**：必须回到 132S 轴高 132 mm；
2. **联轴器长度/护罩间隙**：按实际联轴器；
3. **出口阀顺序**：泵 → 止回阀 → 闸阀 → 压力表，图里只能作参考；
4. **法兰螺栓数量/孔距**：按标准；
5. **泵脚与底座接触**：不能悬空；
6. **吸入口滤网**：必须低于最低水位，且可拆；
7. **管道支架**：出口横管需要支吊架，不能只靠弯头；
8. **电控箱/电缆**：需要进线管、接地、检修空间；
9. **棚架与泵组检修空间**：不能阻挡盘车和拆联轴器；
10. **水面/泥地**：不要做成镜面，保持浑浊和湿痕。
