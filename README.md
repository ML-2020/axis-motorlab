## 电机使用场景模拟

`/scenarios/` 是四个实时三维应用场景并列展示的独立页面，页面主题为电机使用场景，而不是天气或时间。

- **麦田泵站**：电机—联轴器—离心泵—出口管路；麦田、树木、农舍、筒仓与围栏构成现场；
- **室内产线**：室内厂房、窗户外景、输送线、控制柜、货架与班次照明；
- **屋顶冷却**：屋顶机组、轴流风机、栏杆、城市背景与检修通道；
- **水处理搅拌**：搅拌罐、侧入式搅拌器、加药管路、处理车间与湿地植被。

四个场景各自运行独立的 Three.js 场景与相机，同时渲染、持续动画。天气支持 **晴 / 阴 / 雨 / 雪 / 风**，季节支持 **春 / 夏 / 秋 / 冬**；环境控制位于页面顶部，作用于全部场景，但不抢占电机使用场景的叙事主体。
